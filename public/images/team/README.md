# Team / van photos

Drop real photos of your van and crew here (JPG or WebP), then update `content/gallery.json` to point to them, for example:

```json
{
  "src": "/images/team/van-front.webp",
  "alt": "SORI Mobile Tire service van",
  "caption": "Our van"
}
```

Until then the gallery uses the best on-site work photos already in `/public/images`.
